# LebRecycle - Smart Recycling Platform with Admin Panel

## Quick Start

### 1. Install Dependencies (venv active)
```powershell
pip install flask flask-session
```

### 2. Run Server
```powershell
python app.py
```

### 3. Open Browser
- Main site: http://localhost:8000
- **Admin**: http://localhost:8000/admin
  - **Login**: `admin` / `admin`

## Admin Features
- 📍 **Click map to add bins** (new!)
- ✏️ Edit bin location/status  
- 🗑️ Delete bins
- 📊 Live stats dashboard
- Changes instantly update public map

## Features
- 🗺️ Live Lebanon bins map
